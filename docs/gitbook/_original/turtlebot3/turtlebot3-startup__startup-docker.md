# Startup docker

Startup the docker container inside the turtlebot

Make sure you login in via ssh into the turtlebot

Go to the following path

```
cd turtlebot_setup
```

Execute the following command to receive the latest Docker image

```
docker compose pull
```

To start the Docker container, use the `up` command

```
docker compose up
```
