# Location files on wsl

{% hint style="warning" %}
Store all files in the /root/ros\_ws directory otherwise you can lose the files.
{% endhint %}

All files stored in /root/ros\_ws can be found in the Windows directory. Select Linux > the correct distro > home > ubuntu > ros\_ws
