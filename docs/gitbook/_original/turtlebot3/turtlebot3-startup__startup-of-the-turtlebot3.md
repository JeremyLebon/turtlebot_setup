# Startup of the turtlebot3

The turtlebot3 can be powered 2 ways:

* Via DC adapter
* Via battery

Couple the battery with the turtlebot.

The turtlebot should play a sound without interruption.&#x20;

Check if possible the battery voltage of the turtlebot.
